# Git Configuration & Aliases

A collection of practical, security-conscious Git aliases designed to streamline daily workflows while avoiding risky automation.

## Installation & Usage

### Option 1: Copy Directly into Your Global Config

If you prefer to copy the configurations directly, open your global git configuration file (`~/.gitconfig` or `~/.config/git/config`) and append the aliases under an `[alias]` section.

### Option 2: Repository-Specific Installation

To use these aliases in a single repository only, open that repository's local configuration file (`.git/config` inside your project root) and add the `[alias]` block there.
